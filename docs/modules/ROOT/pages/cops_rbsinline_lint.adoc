|===

Checks that there are void types in the return type of `.new` method
`self.new` is a special and fundamental method, and extra care should be taken regarding its return value.
In most cases, assigning it `void` is an unintended mistake.

[#examples-rbsinlinelintnewreturnsvoid]
=== Examples

[source,ruby]
----
# bad
def self.new #: void
end

# good
def self.new #: instance
end

Specifying the `Hash` type for `**` is a very special case and,
in most situations, it is a mistake in type specification.

[#examples-rbsinlinelintrestkeywordhash]
=== Examples

[source,ruby]
----
# bad
# @rbs **opts: Hash[Symbol, String]
def foo(**opts)
end
# e.g.) foo(a: {x: "x"}, b: {y: "y"}, c: {z: "z"})

# good
# @rbs **opts: String
def foo(**opts)
end
# e.g.) foo(a: "x", b: "y", c: "z")

RDoc directives such as `#:nodoc:` are ignored.

[#rbsinlinelintunusedannotation]
== RBSInline/Lint/UnusedAnnotation

|===
| Enabled by default | Safe | Supports autocorrection | Version Added | Version Changed

| Enabled
| Yes
| No
| -
| -
|===

Checks for inline annotations that are not associated with any definition.

An annotation is unused when it is not placed right above the definition
it annotates, or when it names a parameter the method does not have.

[#examples-rbsinlinelintunusedannotation]
=== Examples

[source,ruby]
----
# bad
# @rbs x: Integer

def foo(x)
end

# bad
# @rbs y: Integer
def foo(x)
end

# good
# @rbs x: Integer
def foo(x)
end
----
